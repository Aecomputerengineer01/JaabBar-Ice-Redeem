# ร้านจ๊าบบาร์ (JaabBar) - ระบบตรวจสอบสิทธิ์ & แลกน้ำแข็งฟรีสำหรับนักวิ่งมาราธอน 🧊🏃‍♂️

เว็บแอปพลิเคชันหน้าเดียว (**Single Page Application - SPA**) พัฒนาขึ้นสำหรับ **ร้านจ๊าบบาร์** เพื่อใช้ในการแจกน้ำแข็งฟรีแก่นักวิ่งมาราธอน 1 สิทธิ์ ต่อ 1 หมายเลข BIB ด้วยการจัดเก็บข้อมูลผ่าน `localStorage` ในเบราว์เซอร์ โดยไม่ต้องพึ่งพาฐานข้อมูลภายนอก

---

## ✨ ฟังก์ชันและคุณสมบัติเด่น

1. **ระบบตรวจสอบสิทธิ์ 1 BIB : 1 สิทธิ์ (Strict Anti-Reuse)**:
   - มีช่องกรอกหมายเลข BIB (รับเฉพาะตัวเลข 0-9)
   - มีปุ่ม **"ค้นหา / ตรวจสอบสิทธิ์"**
   - เมื่อกดค้นหา ระบบจะตรวจสอบกับข้อมูลใน `localStorage`:
     - หากเป็นหมายเลข BIB ใหม่ที่ยังไม่เคยใช้สิทธิ์ จะเปิดหน้า **คูปองดิจิทัล**
     - หากหมายเลข BIB นั้นเคยกดรับสิทธิ์ไปแล้ว ระบบจะแสดงหน้าจอแจ้งเตือน Error ทันทีว่า **"สิทธิ์นี้ถูกใช้ไปแล้ว!"** พร้อมระบุวัน-เวลาที่ใช้สิทธิ์ และ**ไม่อนุญาตให้รับคูปองซ้ำอย่างเด็ดขาด**

2. **คูปองดิจิทัล BIB ขนาดใหญ่พิเศษ (Massive Display Text)**:
   - แสดงหมายเลข BIB ขนาดใหญ่สะดุดตา (ตัวหนังสือขนาด 6xl - 8xl แบบเรืองแสง) มองเห็นได้ชัดเจนแม้พนักงานจะอยู่ห่างจากหน้าจอ 2-3 เมตร
   - นาฬิกา Security Live Clock แสดงวินาทีสดแบบเรียลไทม์ ป้องกันการนำภาพแคปหน้าจอเดิมมาวนใช้
   - ดีไซน์บัตรคูปองแบบบัตรคอนเสิร์ต/มาราธอน พร้อมรอยปรุและโทนสีน้ำแข็งเย็นสดชื่น (Ice Glow)

3. **ปุ่ม "ยืนยันรับสิทธิ์" & การบันทึกข้อมูล (localStorage)**:
   - มีปุ่มยืนยันรับสิทธิ์ขนาดใหญ่บนคูปอง
   - เมื่อกดแล้ว ข้อมูลจะถูกบันทึกลง `localStorage` ของเบราว์เซอร์ทันที
   - เอฟเฟกต์เฉลิมฉลอง: พลุกระดาษ Confetti 🎉 หลากสีสัน พร้อมระบบเสียงสังเคราะห์ (Web Audio API Synthesizer) โดยไม่ต้องโหลดไฟล์เสียงภายนอก
   - ระบบการสั่นเตือนบนอุปกรณ์ที่รองรับ (Haptic Feedback Vibration)

4. **การออกแบบสไตล์ Mobile-First**:
   - ออกแบบ UI ให้พอดีกับหน้าจอมือถือโดยเฉพาะ (Touch-friendly buttons, ขนาดปุ่มกดมาตรฐาน)
   - แป้นพิมพ์ตัวเลขเปิดขึ้นมาอัตโนมัติบนสมาร์ทโฟน (`inputmode="numeric"`)
   - ชิปปุ่มกดทดสอบด่วน (Quick Test BIB Chips: #42195, #21097, #1008, #888) สะดวกต่อการสาธิตและทดสอบ

5. **ระบบจัดการสำหรับเจ้าหน้าที่ร้าน (Staff History Drawer)**:
   - ปุ่มดู **"ประวัติ"** ที่มุมขวาบน แสดงจำนวนสิทธิ์ที่แจกไปแล้วทั้งหมดแบบเรียลไทม์
   - รายการ BIB แต่ละตัวที่ใช้สิทธิ์ พร้อมวัน-เวลาที่บันทึก และรหัสอ้างอิง (Ref Code)
   - มีช่องค้นหาประวัติ BIB ในรายการ
   - มีปุ่ม **"ล้างข้อมูลเพื่อเริ่มใหม่" (Reset Data)** เพื่อความสะดวกในการทดสอบระบบซ้ำ

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ได้ทันที
สามารถดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเบราว์เซอร์ใดก็ได้ (Chrome, Safari, Edge, Firefox) โดยไม่ต้องติดตั้งโปรแกรมเซิร์ฟเวอร์เพิ่มเติม

### วิธีที่ 2: รันผ่าน Local Server (แนะนำสำหรับทดสอบบนมือถือผ่านเครือข่าย Wi-Fi)
เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```bash
# ใช้ Python (ถ้ามีติดตั้งไว้):
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`

## 🧪 ขั้นตอนการทดสอบตามเงื่อนไข (Test Cases)

1. **ทดสอบแลกสิทธิ์ครั้งแรก (Pass)**:
   - แตะที่ปุ่มตัวอย่าง `#42195` หรือพิมพ์หมายเลข BIB ในช่อง
   - กดปุ่ม **"ค้นหา / ตรวจสอบสิทธิ์"**
   - จะเห็นหน้าจอ **คูปองดิจิทัล** ที่มีเลข BIB ขนาดใหญ่มาก
   - กดปุ่ม **"ยืนยันรับสิทธิ์ (กดรับน้ำแข็ง)"**
   - หน้าจอจะแสดงพลุฉลอง 🎉 และแจ้งสถานะ **"รับสิทธิ์สำเร็จแล้ว!"**

2. **ทดสอบป้องกันการรับสิทธิ์ซ้ำ (Strict Error Prevention)**:
   - กดปุ่ม **"กลับสู่หน้าแรก"**
   - กรอกหมายเลข `#42195` ซ้ำอีกครั้ง
   - กดปุ่ม **"ค้นหา / ตรวจสอบสิทธิ์"**
   - **ผลลัพธ์:** ระบบจะปฏิเสธทันที และแสดงหน้าเตือนสีแดงพร้อมเสียง Alert:
     > ❌ **"สิทธิ์นี้ถูกใช้ไปแล้ว!"**
     > พร้อมระบุวัน-เวลาที่เคยใช้สิทธิ์ และไม่อนุญาตให้เปิดคูปองซ้ำ

3. **ทดสอบรีเซ็ตข้อมูล**:
   - กดปุ่ม **"ประวัติ"** ที่มุมขวาบน
   - จะเห็นประวัติ BIB `#42195` บันทึกอยู่
   - กดปุ่ม **"ล้างข้อมูลเพื่อเริ่มใหม่"** เพื่อลบประวัติใน `localStorage` แล้วเริ่มทดสอบใหม่ได้ทันที
